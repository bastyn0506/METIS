# METIS (Monitoring Endpoint Traffic Intelligence System)

METIS is a lightweight real-time network traffic visualizer built with Python and Unity.  
It is designed to help beginners and security enthusiasts understand network behavior through 3D visualization and threat scoring.

## 🚀 Features

- Real-time packet capture and visualization
- Port scan detection and alerting
- Threat score calculation using IP/domain IoCs
- Dangerous port monitoring
- Unity-based 3D interface for packet flow visualization
- Syslog integration
- GeoIP-based country mapping

## 📂 Project Structure

- `packet_sniffer.py`: Python backend for packet analysis and threat detection
- `interface.py`: HTTP/Unity communication logic
- `fetch_threatfox_iocs.py`: IoC auto-fetching script using ThreatFox API
- `Unity/`: Unity project for the 3D front-end
- `logs/`: Logs generated by METIS

## 🔧 Requirements

- Python 3.10+
- Scapy
- geoip2
- Unity 2022.3+

## 🌐 Data Sources

- [ThreatFox](https://threatfox.abuse.ch/)
- GeoLite2 Country DB

## 🛡 Use Case

Ideal for:

- Security education
- Proof-of-concept in threat detection
- Visualizing home network traffic
